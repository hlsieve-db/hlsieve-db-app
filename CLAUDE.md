# HLSieve DB Claude Code Rules

Before starting any task, read and follow
[`docs/ai-working-rules.md`](docs/ai-working-rules.md). It is the mandatory
common rule set for this repository.

Use Minimal Context / Scoped Task Mode:

- Search first and read only the files needed for the current task.
- Never scan the entire repository as routine preparation.
- Use targeted tests during implementation and the full gate after completion.
- Do not expand scope without a task-specific reason.
- Do not commit or push without explicit approval.
